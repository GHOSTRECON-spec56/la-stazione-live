# La Stazione · version 3

Independent static preview at `/redesign_v3/`. V1, V2, `/redesign/` and the original homepage remain available separately.

This version pairs original café ink illustrations with physical, playful motion inspired by the user's Chun and Sunbeam references. `index.html` and `style.css` define the poster composition; `app.js` and `motion.css` provide the hero, scroll spread, illustrated wheel, optional coffee-break toss, menu/gallery navigation, and global motion controls. All content remains visible with motion disabled.

`menu.js` and `menu.css` supply the complete searchable 103-item menu from `../menu-data.js`, with USD/LBP prices. Google Maps is embedded at the verified location. Full-size gallery images are loaded from `../gallery/` on demand. `photos/`, `fonts/` and `vendor/` are local assets. `art/cafe-illustrations.webp` is the original transparent four-part illustration sheet; provenance and exact generation prompt are recorded in the private project documentation.

Serve the parent `public` directory and open `/redesign_v3/`. No build or runtime dependency installation is required.
